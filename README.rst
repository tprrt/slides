================
My Public Slides
================

This repository contains the slides of my public talks on Linux systems, embedded security and build systems.

Presentations
=============

Each talk lives in a directory named after its date (``YYYYMMDD``) and contains the slides as a PDF.
Some talks also ship the editable ``.odp`` source or the ``.pdfpc`` speaker notes used with
`pdfpc <https://pdfpc.github.io/>`_.
